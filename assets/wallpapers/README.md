# Cosmos wallpapers

One picture per accent colour, supplied by the project owner on 2026-11-28.

**Their authors and licences are not recorded.** They are not covered by this
repository's MIT licence. Before a public release, confirm that each may be
redistributed and credit it here, or replace it.

`python3 scripts/import-wallpapers.py` crops them to 16:9 and enlarges them to
1920x1080. The originals are only about 735 pixels wide, so they look soft;
drop in larger originals under the same names and run the script again.
